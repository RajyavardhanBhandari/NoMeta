# Phase 2 — Upload Experience

Status: Complete

## Implemented
- Drag-and-drop image intake
- Native file picker
- Multiple image selection
- JPG/JPEG, PNG and WebP validation
- 50 MB per-file limit
- 25-file batch limit
- Duplicate prevention within the current queue
- Object URL thumbnail previews
- File name and size display
- Individual remove
- Clear all
- Drag-over state
- Accessible hidden file input
- Error messaging
- Mobile-responsive queue
- Local-only copy and UX reassurance
- Scanner action hook reserved for Phase 3

## V1 boundary
HEIC/HEIF is intentionally not accepted yet. It will only be enabled after reliable browser decoding and metadata behavior is validated.
