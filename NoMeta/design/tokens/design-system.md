# NoMeta Design System — Phase 1

## Product personality
Quiet confidence, privacy-first, editorial clarity, technical precision.

## Principles
1. Explain before asking.
2. Never use fear as the primary conversion tactic.
3. Use color semantically, not decoratively.
4. Keep the user's photo and privacy state visually central.
5. Motion should clarify state changes, never distract.

## Type
Inter/system sans. Display: tight tracking and compact line-height. Body: 16–18px with generous line-height.

## Color semantics
Ink: #111111 · muted ink: #666666 · canvas: #FAFAF8 · surface: #FFFFFF · line: #E8E8E3 · green: #157347 · amber: #9A6500 · red: #B42318 · blue: #2457C5.

## Shape
Default radius 14px. Small controls 10px. Large cards 20–24px.

## Spacing
4px base scale; common layout spacing 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128.

## Accessibility
Keyboard-visible focus, minimum comfortable touch targets, semantic buttons/links, no color-only status, respect prefers-reduced-motion.
