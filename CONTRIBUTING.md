# Contributing to NoMeta

Thanks for helping improve NoMeta.

## Getting started

1. Fork the repository.
2. Create a focused branch for your change.
3. Make a small, clearly described improvement.
4. Open a pull request against `main`.

## Good first contributions

- Documentation improvements
- Accessibility fixes
- UI polish
- Bug fixes
- Tests

## Pull requests

Please explain what changed, why it changed, and how you tested it.

## Code of conduct

Be respectful, constructive, and welcoming to other contributors.
