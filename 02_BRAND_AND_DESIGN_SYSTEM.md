# NoMeta — Brand & Design System

Phase 1 implementation lives in `components/ui`, `components/privacy`, `app/globals.css`, and `design/tokens/design-system.md`.

## Personality
Quiet confidence · privacy-first · editorial clarity · technical precision.

## Visual direction
Premium and minimal rather than “hacker” or surveillance-themed. Near-black ink, warm off-white canvas, restrained borders, semantic green/amber/red.

## Core components
- Logo
- Navigation
- Button variants
- Card
- Badge
- Icon system
- Privacy score
- Metadata row
- Cleaning mode selector

## Responsive breakpoints
Desktop-first composition with tablet and mobile adaptations. Core actions remain touch-friendly.

## Accessibility
Visible focus, semantic controls, readable contrast, no color-only status, reduced-motion support.
